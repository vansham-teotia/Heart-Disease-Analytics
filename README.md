# Heart Disease Analytics | Python & Power BI

## Project Overview

This project focuses on analyzing heart disease data through **Python-based Exploratory Data Analysis (EDA) and an interactive Power BI dashboard**. The objective is to explore patient demographics, clinical risk factors, disease prevalence, and severity patterns through data analysis and visualization.

## Technologies Used

- **Python** — Data analysis and preprocessing
- **NumPy** — Numerical operations and feature engineering
- **Pandas** — Data manipulation, cleaning, and transformation
- **Matplotlib** — Data visualization
- **Seaborn** — Statistical visualization and correlation analysis
- **Microsoft Power BI** — Interactive dashboard development
- **Google Colab** — Python notebook development

## Project Workflow

### 1. Python Data Analysis
- Imported and explored the heart disease dataset.
- Renamed columns for better readability.
- Created disease-status categories and age groups.
- Examined missing values, duplicate records, data types, and descriptive statistics.
- Prepared the data for exploratory analysis.

### 2. Exploratory Data Analysis (EDA)
- Analyzed overall heart disease distribution.
- Compared disease cases across age groups and gender.
- Explored chest pain types and cholesterol distributions.
- Created a clinical feature correlation heatmap using Seaborn.
- Exported the processed dataset to CSV.

### 4. Power BI Dashboard
Developed an interactive dashboard featuring:

- Total patients and disease cases
- Overall disease rate
- Clinical risk factor prevalence
- Disease rates by age group and gender
- Cardiovascular health indicators
- Disease severity distribution
- Interactive filters for age group, gender, risk level, and data source

## How to Run

1. Clone or download this repository.
2. Open the Jupyter Notebook in Google Colab or Jupyter Notebook.
3. Install the required libraries if they are not already available: `pandas`, `numpy`, `matplotlib`, and `seaborn`.
4. Update the dataset path to match your environment.
5. Run the notebook cells in order.
6. Open the `.pbix` file using Microsoft Power BI Desktop to explore the dashboard.
